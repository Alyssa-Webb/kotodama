# Musashi reference (Tripo)

Turnaround renders of a chibi Miyamoto Musashi model generated in Tripo (text-to-3D) by the owner,
rendered from eight angles for Gemini 4 Argon to draw the 2D Dojo Master from. **Reference only:**
the game stays 2D (ADR 0007/0008); no 3D model ships in the app.

The source model (`musashi-tripo.glb`, 6 MB) is git-ignored; it lives on Ken's PC.

Known gap: the wakizashi reads as a stub beside the katana. The 2D art must show both swords.
