# Ukiyo-e Woodblock Print (Nishiki-e)

Each clip steps at 12 fps through discrete `<g class="f ...">` frame groups via opacity-only CSS keyframes, treating every pose like a freshly pulled woodblock impression whose flat mineral-pigment fills and varied-weight sumi contours register against a still _bokashi_ and _seigaiha_ print ground. Fluidity and weight come from hand-staged overlap and squash-and-stretch rather than interpolated transforms: the topknot, wide kimono sleeves, and yellow _obi_ knot lag a beat behind the walk bob, slow breath, and _bokken_ lunge, while carved crescent smear blocks carry the swing into impact.
