# Tripo inputs

Large screenshots of the game's own 2D characters (light theme, white background) to upload to
Tripo's **image-to-3D**, so the generated models match the existing art. The models are reference
only (turnarounds and pose references for Gemini 4 Argon); nothing 3D ships in the app.

- `koto.png`, `avatar.png` (+ `avatar-back.png` as a second view): full bodies, use image-to-3D.
- `akari.png`, `tetsu.png`: the guides are drawn as busts, so use the text prompts in the chat
  log / room note for a full body and treat these as the face and costume reference.
