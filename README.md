A free, offline-first web app that teaches Japanese as a game: a journey through a yokai-filled Japan, where right answers are attacks, money is real yen and Koto the word-spirit guides you. Install it from Safari
(Share → Add to Home Screen on iPhone, File → Add to Dock on Mac).

- Play: https://alyssa-webb.github.io/kotodama/
