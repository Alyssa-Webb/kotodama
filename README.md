# Kotodama 言霊

A free, offline-first web app that teaches Japanese as a hardcore game. Install it from Safari
(Share → Add to Home Screen on iPhone, File → Add to Dock on Mac).

- Play: https://alyssa-webb.github.io/kotodama/
- Product plan: [PLAN.md](PLAN.md) · Engineering rules: [CLAUDE.md](CLAUDE.md)
- Writing lessons with ChatGPT: [AUTHORING.md](AUTHORING.md)
- Morning report / launch steps: [LAUNCH.md](LAUNCH.md)

```bash
npm install
npm run dev     # live coding
npm run check   # everything CI runs
```
