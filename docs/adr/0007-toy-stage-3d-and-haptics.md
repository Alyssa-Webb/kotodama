# 0007 — 3D plastic-toy stage and haptics (owner-requested VX pass)

- Context: the owner asked for a far more alive, game-like feel that does not read as a Duolingo clone: a training-start transition (bushes and fog clearing into a bamboo grove, shrine or dojo), 3D "plastic model" items in the shop, and animation plus haptics for correct answers, finished sections, dojos and purchases. CLAUDE.md assigns final visual design to ChatGPT; as in ADR 0006, the owner chose not to wait.
- Decision:
  - three.js (WebGL2), lazy-loaded as its own chunk and pre-warmed when idle. Two canvases share one frame loop: a backdrop world behind training screens and a front layer for the gate, effects, reveals and item views (rendered with scissor rects, so the shop needs no extra WebGL contexts). WebGPU was skipped: WebGL2 runs on every target device, and these scenes are limited by fill rate, not draw-call overhead.
  - Every model is procedural (rounded primitives with one shared clearcoat "lacquer toy" material and a generated studio environment map), so there are no model files to download or precache, and colors come from `design/toys.json` (palette, plastic look, gate timing, scene per training kind).
  - A frame-time governor (`src/foundations/toy/quality.ts`, unit-tested) keeps motion smooth on every device. It lowers resolution first, then drops a quality tier, and only climbs back after sustained fast frames. The tier is stored per device in localStorage, never in the save or backups.
  - Haptics: one named vocabulary in `design/animations.json` (tick, tap, thud, pop, double, rise, heartbeat, roll). Each animation slot can name a haptic and a toy effect. Android plays the vibration patterns. iPhone Safari has no vibration API, so a toggled native `<input switch>` gives one light tick per pulse. Rich iOS haptics would need a native wrapper, which was rejected: a sideloaded app gets its own IndexedDB (progress would split from the PWA's), and free signing expires every 7 days.
  - Reduced motion skips all 3D motion; haptics drop to a single tick.
- Consequences: the main chunk is unchanged; the stage chunk is about 160 KB gzipped and precached for offline use. ChatGPT can still restyle everything as data (palette, timings, slot effects, haptics). Hand-made glTF models can later replace `itemModel()` behind the same ids.
